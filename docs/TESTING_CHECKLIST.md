# Testing Checklist

- [ ] Load a valid CSV file.
- [ ] Try a missing CSV path.
- [ ] View dataset dimensions and data types.
- [ ] Run statistics with numeric columns.
- [ ] Run statistics on a dataset without numeric columns.
- [ ] Check missing-value totals.
- [ ] Check highest and lowest numeric values.
- [ ] Filter using an existing column.
- [ ] Filter with no matching records.
- [ ] Enter an invalid menu option.
- [ ] Display the complete dataset.
- [ ] Exit from the menu.
