# Feature Reference

## Dataset Information
Shows row count, column count, column names, and detected data types.

## Statistics
Calculates mean, median, standard deviation, minimum, and maximum for numeric columns.

## Missing Values
Reports missing values for every column and the dataset-wide total.

## Filtering
Supports case-insensitive partial matching against a selected column.

## Summary Report
Combines dataset structure, missing-value information, and numeric summaries.
