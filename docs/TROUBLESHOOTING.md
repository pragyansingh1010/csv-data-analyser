# Troubleshooting

### `Could not load the CSV file`
Check that the path is correct and that the file is a readable CSV.

### `Column not found`
Use the exact column name displayed under available columns.

### `No numerical columns found`
The statistics and min/max features require columns that Pandas recognizes as numeric.

### Empty filter result
Try a different search value or verify that the selected column contains the expected text.
