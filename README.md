# CSV Data Analyzer

A Python command-line tool for exploring CSV datasets with Pandas and NumPy.

## Features
- Dataset information
- Numerical statistics
- Missing-value analysis
- Highest and lowest values
- Text-based filtering
- Summary reports
- Full dataset display

## Requirements
```bash
pip install pandas numpy
```

## Run
```bash
python "csv data analyser.py"
```

Enter the path to a CSV file when prompted.
